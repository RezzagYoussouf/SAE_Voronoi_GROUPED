## A) Résumé

Application Python en ligne de commande (CLI) qui :

1. Lit un fichier texte de points 2D (format `x,y`).
2. Calcule le diagramme de Voronoï correspondant via **scipy**.
3. Visualise le diagramme avec **matplotlib** (zoom/pan interactif avec `--show`).
4. Exporte en **SVG** (obligatoire) et/ou **PNG** (optionnel).

**Choix technologiques :**
| Bibliothèque | Justification |
|---|---|
| `scipy.spatial.Voronoi` | Algorithme Fortune (O(n log n)), bibliothèque scientifique standard, bien testée |
| `matplotlib` | Export SVG/PNG natif, interactivité zoom/pan, testable avec backend `Agg` |
| `pytest` + `pytest-cov` | Standard industriel, support AAA, couverture de code intégrée |
| `argparse` | Inclus dans la stdlib, pas de dépendance supplémentaire, KISS |

### Application des principes SOLID

| Principe | Application |
|---|---|
| **S** – SRP | Chaque module a **une seule raison de changer** : `point_parser` ne fait que du parsing, le renderer ne fait que du rendu. |
| **O** – OCP | `BaseRenderer` / `BaseExporter` permettent d'ajouter de nouveaux formats sans modifier le code existant. |
| **L** – LSP | `MatplotlibRenderer` et `SVGExporter` / `PNGExporter` sont substituables à leurs bases sans altérer le comportement. |
| **I** – ISP | `BaseRenderer` n'expose qu'une seule méthode `render()` ; `BaseExporter` qu'une seule méthode `export()`. |
| **D** – DIP | `CLIRunner` dépend de `BaseExporter` (retourné par la factory), pas de `SVGExporter` directement. |

### Design patterns utilisés

- **Strategy** : `MatplotlibRenderer` est une stratégie de rendu interchangeable via `BaseRenderer`.
- **Factory** : `ExporterFactory.create("svg")` découple la création des exporteurs des appelants.
- **Value Object** : `Point` est immutable (`frozen=True`), hashable, équatable.

## C) Installation et exécution

### Prérequis

- Python 3.11+
- pip

### Installation

```bash
# Depuis le répertoire phase2/
cd phase2
pip install -r requirements.txt
```

### Lancer l'application

```bash
# Aide complète
python main.py --help

# Export SVG (défaut)
python main.py -i data/points.txt

# Export SVG + PNG dans un répertoire de sortie
python main.py -i data/points.txt -o output/diagram -f svg -f png

# Afficher la fenêtre interactive (nécessite un affichage graphique)
python main.py -i data/points.txt --show

# Sans axes ni grille
python main.py -i data/points.txt --no-axes -f svg
```

**Options CLI :**

| Option | Description |
|---|---|
| `-i FILE` / `--input FILE` | Fichier d'entrée (obligatoire) |
| `-o STEM` / `--output STEM` | Nom de sortie sans extension (défaut: `voronoi_output`) |
| `-f FORMAT` / `--format FORMAT` | `svg` ou `png` ; répétable pour plusieurs formats (défaut: `svg`) |
| `--show` | Affiche la fenêtre interactive matplotlib |
| `--no-axes` | Masque les axes et la grille |

### Lancer les tests

```bash
# Depuis le répertoire phase2/
pytest
```

### Générer le rapport de couverture

```bash
# Rapport terminal
pytest --cov=src --cov-report=term-missing

# Rapport HTML (ouvrir htmlcov/index.html)
pytest --cov=src --cov-report=html
```

## F) Qualité et maintenance

### Comment les anti-patterns sont évités

| Anti-pattern | Mesure prise |
|---|---|
| **God Class** | Aucune classe > 120 lignes ; responsabilités strictement séparées |
| **Magic Numbers** | Toutes les constantes sont nommées (`EDGE_COLOR`, `DEFAULT_DPI`, etc.) |
| **Code Spaghetti** | Pipeline linéaire dans `CLIRunner._execute_pipeline` en 5 étapes nommées |
| **Dépendances circulaires** | `models` ← `parser/voronoi/rendering/export` ← `cli` (arbre acyclique) |
| **Duplication** | `_ensure_parent_dir` mutualisé dans `BaseExporter`; fixtures pytest dans `conftest.py` |

### Limites connues

1. Les arêtes infinies sont étendues par une heuristique (INFINITE_EDGE_EXTENSION_FACTOR) ; sur des nuages très allongés, quelques arêtes peuvent déborder légèrement.
2. Le mode `--show` requiert un backend graphique (non disponible dans les environnements headless / CI).
3. Pas de support des séparateurs alternatifs (`;`, tabulation) – par conception KISS.

### Pistes d'amélioration

- Ajouter un séparateur configurable via `--sep`.
- Implémenter un export PDF (en ajoutant `PDFExporter` sans modifier le reste).
- Interface web légère avec Streamlit (nouveau renderer + nouveau exporter).
- Cache du résultat Voronoï pour de grandes listes de points.
